# MACROMATE
# 🥗MacroMate – AI Nutrition Tracker

MacroMate is an AI-powered nutrition assistant that analyzes meal images and provides estimated nutritional information. Users can upload a meal photo to get calories, protein, carbohydrates, and fat estimates, ask nutrition-related questions, and send nutrition results to Telegram.

# 🚀Live Demo

https://macromate-qv8gxzpfkmtm9m3nmvrut6.streamlit.app

# ✨Features

- 📸 AI-powered meal image analysis
- 🔥 Estimated calories
- 💪 Estimated protein
- 🍚 Estimated carbohydrates
- 🥑 Estimated fat
- 💬 AI nutrition chatbot
- 📲 Send nutrition results to Telegram
- 🎨 Simple and beginner-friendly Streamlit interface

## 🛠️Technologies Used

- Python
- Streamlit
- Google Gemini API
- Google GenAI SDK
- Pillow
- Requests
- Telegram Bot API
